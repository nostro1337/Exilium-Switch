# Правила форматирования ответов

## Форматирование таблиц и структурированных данных
- **Таблицы в чате:** Все таблицы, списки параметров, сравнения и структурированные данные в сообщениях чата необходимо оформлять исключительно через нативный Markdown (`| колонка | колонка |`), чтобы они корректно и визуально привлекательно рендерились интерфейсом.
- **Mermaid-диаграммы:** Запрещено отправлять Mermaid-код напрямую в текстовые сообщения чата. Использовать Mermaid только при создании графических схем/диаграмм внутри **артефактов** (`.md` документов).
